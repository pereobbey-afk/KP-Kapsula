# Яндекс Директ — проект

Рабочий проект для ведения рекламных кампаний в Яндекс Директе: структура кампаний, ключевые слова, объявления, отчёты и анализ.

## Структура папок

| Папка         | Назначение                                                                 |
|---------------|----------------------------------------------------------------------------|
| `data/`       | Исходные загружаемые файлы (выгрузки, брифы, семантика, прайсы и т.д.)      |
| `campaigns/`  | Структура рекламных кампаний (группы объявлений, настройки)                 |
| `keywords/`   | Списки ключевых слов, минус-слова, кластеризация                           |
| `ads/`        | Тексты объявлений, заголовки, быстрые ссылки, уточнения                     |
| `reports/`    | Отчёты и аналитика по кампаниям                                             |
| `exports/`    | Готовые файлы для загрузки в Директ (XLSX/CSV, шаблоны Директ Коммандера)   |

## Как начать работу

1. Загрузите исходные файлы в папку `data/` (или в подходящую тематическую папку).
2. Напишите, что нужно сделать — например: собрать семантику, написать объявления,
   проанализировать выгрузку, подготовить файл для загрузки в Директ.
