# Где мы остановились

Дата последней записи: 12 августа 2026.

Этот файл существует, чтобы работу можно было продолжить с любого места,
не восстанавливая контекст по переписке.

## Что готово

- **Приложение целиком.** Устойчивый асинхронный конвейер: веб-сервер
  создаёт задачу, отдельный процесс воркера считает. Расчёт не привязан
  к HTTP-запросу и переживает перезапуск любого процесса — это была
  первопричина исходного дефекта. Регрессия зафиксирована
  в `tests/job-queue.test.ts`.
- **Прайс-лист.** Обе редакции разбираются и объединяются: 951 работа,
  19 разделов. Материалы отсекаются, неоднозначные позиции сохраняются
  с предупреждением.
- **Методика «Капсулы» восстановлена** по паре «проект + смета» объекта
  1191 и проверена построчно. Подробности — `docs/methodology.md`.
  Правила — `src/domain/estimate/derive.ts`, ожидания в
  `tests/derive.test.ts` заданы числами настоящей сметы.
- **Результат сверки:** расчёт вывел 28 позиций, все 28 есть в смете,
  объём совпал точно у 24. Закрыто 61,9 % суммы (2 470 040 ₽
  из 3 989 675 ₽).
- `npm run verify` зелёный: 143 теста, сборка проходит.

## Что отключено намеренно

**Предварительный расчёт по площади** (`preliminary.ts`, `geometry.ts`,
`ruleset.ts`) — маршрут отвечает `VALIDATION_FAILED`, кнопка из интерфейса
убрана. Причина: коэффициенты были выдуманы, результат разошёлся
с реальностью в разы. Включать обратно нельзя, пока правила не выведены
из настоящих данных. Код оставлен как история решения, а не как рабочий
путь.

## Чего ждём от «Капсулы»

1. **Ответ сметчика: откуда взялось 66 подрозетников.** Ведомость
   электроблоков проекта 1191 даёт 95 механизмов (49 блоков, сумма
   размеров рамок). В смете стоит 66 — и подрозетников, и механизмов,
   и коронений (46 по ПГП + 20 по бетону). Разница 29 штук ≈ 40 000 ₽.
   Пока ответа нет, правило считать по ведомости оставлено как есть,
   расхождение видно в сверке.
2. **Вторая пара «проект + смета»** по другому объекту. Все правила
   выведены по одному объекту; на втором их надо перепроверить, прежде
   чем считать доказанными.
3. **Ключ `ANTHROPIC_API_KEY`** и адрес развёртывания — без них
   не закрыть публикацию и e2e на живом сервере.

## Что делать дальше, когда данные появятся

- Прогнать новую пару через ту же сверку (команды в конце
  `docs/methodology.md`) и посмотреть, какие правила устояли.
- Закрыть оставшиеся 38 % сметы: сантехника, электрика, изделия
  из керамогранита. Величины в проекте есть, но не готовыми суммами —
  их надо считать по планам и привязкам, а часть сметчик берёт круглыми
  числами с запасом (кабель 200 м, гофра 300 м). Это отдельное правило,
  а не измерение.
- Исправить в прайс-листе позицию «Подготовка / уборка пола под
  покрытие»: у неё не заполнена единица измерения, поэтому импорт её
  отклоняет. В смете 1191 она стоит на 17 485 ₽.
