# Методика расчёта объёмов «Капсулы»

Документ восстановлен по паре «дизайн-проект + смета» одного объекта:
квартира 1191, улица Академика Волгина, 78,06 м².

Все соотношения ниже **проверены точным совпадением** чисел проекта и
сметы, а не выведены предположительно.

## Главный вывод

**Объёмы берутся из ведомостей проекта, а не выводятся из площади.**

Дизайн-проект содержит готовые сводные площади по каждому виду отделки.
Сметчик переносит их в смету напрямую. Поэтому расчёт «по площади и числу
комнат» не воспроизводит смету ни при какой калибровке коэффициентов:
состав и объёмы определяются проектными решениями, а не геометрией.

## Структура дизайн-проекта

Проект сделан в ArchiCAD, PDF **векторный с текстовым слоем** (не скан).
Текст в кодировке CP1251; при чтении как Latin-1 требуется перекодировка.
Это важно: ведомости читаются извлечением текста, без распознавания
изображений — быстрее, дешевле и точнее.

Листы, из которых берутся объёмы:

| 08. План чистовой отделки пола | площади напольных покрытий, длина плинтуса |
| 09–10. Схема тёплого пола | площадь тёплого пола |
| 17. Ведомость осветительных приборов | количество светильников |
| 20–24. Ведомость розеток | количество розеток, выключателей, выводов |
| 26. Ведомость отделки стен | площади по каждому виду настенной отделки |

## Что это означает для правил расчёта

1. **Обои и покраска идут по одной площади и складываются.** Технология
   называется «Обои под покраску + покраска»: обои клеятся, затем
   красятся. Это не взаимоисключающие варианты.

2. **Малярный цикл идёт не по всей площади стен.** Стены делятся по видам
   отделки: под покраску, под плитку, под панели. Каждый вид имеет свою
   площадь в ведомости, и работы применяются только к своей.

3. **Гидроизоляция считается по площади плитки**, а не по площади мокрых
   зон: стены плюс пол под плиткой.

4. **Состав работ определяется проектом.** В этой смете нет штукатурки
   стен, стяжки и натяжного потолка — соответствующих решений нет в
   проекте. В смете другого объекта (70 м²) штукатурка есть, объём 226 м².
   Набор разделов нельзя задать константой.

5. **Площади отдельных помещений тоже используются.** Шумоизоляция
   потолка взята равной площади спальни, а не всей квартиры.

## Роль ИИ и роль кода

ИИ читает проект и извлекает **исходные величины**: площади из ведомостей
и экспликации, количества из ведомостей розеток и светильников, длины из
планов. У каждой величины есть проверяемый источник — лист и строка.

Код детерминированно **выводит производные величины** по правилам выше
(гидроизоляция = плитка стен + плитка пола) и умножает объём на цену
активного прайса.

Такое разделение сохраняет прежний барьер: модель не видит цен и не
считает деньги, а все арифметические связи проверяемы и покрыты тестами.

## Ограничения этого документа

- Восстановлено по **одному** объекту. Правила гидроизоляции и грунтовки
  подтверждены единственным совпадением — на втором объекте их надо
  перепроверить.
- Расхождение по бамбуковым панелям (64,18 против 63,74) не объяснено.
- Количество розеток в смете (66 подрозетников) с ведомостью построчно не
  сверялось: ведомость перечисляет рамки и вставки, требуется разбор
  таблицы.
- Смета 70 м² содержит материалы (68 000 ₽, тип «мат»), смета 78 м² —
  нет. Правило включения материалов не установлено.
